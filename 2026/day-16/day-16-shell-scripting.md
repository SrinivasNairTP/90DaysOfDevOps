# Day 16 – Shell Scripting Basics

## Overview
This task covers fundamental shell scripting concepts including shebang, echo, variables, and conditional statements.

## Key Concepts Covered

### Shebang
- Used to specify which interpreter should execute the script

### Echo
- Completed tasks to print output using `echo`

### Variables
- Practiced printing values using shell variables

### Conditional Statements

#### Simple If-Else
- Check if a file exists or not
- Verify if a number is positive, negative, or zero

#### Nested If-Else
- Check service status based on user input (yes/no)
- Print status accordingly or skip based on conditions
